RUNNING THIS PROGRAM OVER A NETWORK — section 13
================================================================================

If you modify this program and let anyone use the modified version over a
network, section 13 requires you to offer those users the source code of YOUR
modified version.

To make this easy, the program shows a "Mã nguồn" (source code) link in its
interface, taken from the "sourceUrl" field of data/config.json. If you modify
the program, point that field at your own published source. If you do not
modify it, leave it pointing at the original repository and you are compliant.
